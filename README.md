\# SalesIn



\## Inteligência Comercial 360



\*\*Dados • Estratégia • Resultados\*\*



O SalesIn é uma plataforma pessoal de portfólio voltada para gestão, análise e inteligência comercial.



O projeto utiliza exclusivamente dados fictícios e não deve utilizar informações comerciais reais ou confidenciais de empresas.
